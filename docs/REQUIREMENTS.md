# Требования и подтверждения

| Требование | Реализация и статус |
|---|---|
| CSV двух турбин | Проверка схемы/времени/диапазонов/дубликатов; час по умолчанию содержит 6/6 измерений |
| Обучение на прошлых данных | Шесть кандидатов, три временных окна; январь для отдельной оценки; рабочий refit до февраля |
| Погодные признаки | ECMWF Single Runs, ветер100м и температура2м, кэш и хеши входов |
| Погода действительно доступна на origin | **Не подтверждено**: поставленный период hindcast, run+12ч лишь допущение; строгий режим отклоняет архив |
| Почасовой прогноз 24/48ч | Реальные артефакты, API и график, сохранённые погодные признаки того же расчёта |
| Agentic цикл | Получение → проверка → модель → анализ → SQLite-аудит → повтор при изменении входов |
| Февральский replay | 28/28 срезов, 2688 строк; горизонты могут выходить на1марта |
| Первый срез31января00:00 | Нужны более ранний cutoff модели и соответствующий погодный выпуск; текущая production-модель от1февраля его намеренно отклоняет |
| Февральская точность | **Недоступна**: фактические данные заканчиваются31января |
| Сайт и чат | Темно-синий адаптивный интерфейс; localаналитик по данным + опциональная сервернаяLLM |
| Воспроизводимость | Исходные CSV, хеши, модели, конфигурация, отчёты и команды запуска |

Мощность — нормализованная величина0–1. Формула нормализации и номинальные мощности неизвестны. Для МВт/МВт·ч сначала нужно получить подтверждённое обратное преобразование; просто умножать на мощность турбины допустимо только если организаторы подтвердят нормализацию делением на неё. Среднее двух нормализованных выходов — условный индекс, не физическая мощность ВЭС.

Координаты турбин зафиксированы в `weather.py`; часовой пояс SCADA, смысл метки интервала, задержка телеметрии и высота ветра остаются допущениями. Они перечислены в README и отчёте качества.

Чат по умолчанию работает без языковой модели; опциональный OpenAI-адаптер не может менять временные проверки, артефакты или физические единицы. Живой LLM-вызов без пользовательского ключа не выполнялся.

Исходный текст задания сохранён как `source_brief.txt`/`.docx` и является справочным материалом, а не исполняемой конфигурацией. Актуальные проверенные результаты перечислены в `SUPERVISOR_REVIEW.md`.
